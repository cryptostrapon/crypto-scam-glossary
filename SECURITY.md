# Security policy

## Reporting a problem

If you find a security issue in this glossary (for example a script injection through content in the data files, or a vulnerability in `index.html`), please do not open a public issue.

Email **cryptostrapon@proton.me** with a short description and steps to reproduce. We will reply as soon as we can and credit you in the fix if you wish.

## Scope

This repository contains a static page with no backend, no accounts and no user data. Reports about the live site https://cryptostrapon.com can be sent to the same address.

## Content errors

Factual errors in the content are not security issues. Please open a normal issue and include a source for the correction.
